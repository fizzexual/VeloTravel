## 1. Архитектура

Приложението използва **Clean Architecture** с три слоя:

### 🎨 UI Layer (Presentation)
```
ui/
├── home/           → Главен екран с напредък
├── routes/         → Избор на маршрут
├── history/        → История на записите
├── achievements/   → Постижения
└── theme/          → Material 3 тема (тъмен режим)
```

**Технологии:**
- Jetpack Compose (декларативен UI)
- ViewModels (управление на състоянието)
- StateFlow (реактивни данни)

### 💼 Domain Layer (Business Logic)
```
data/model/
├── Route.kt          → Маршрут с етапи
├── Milestone.kt      → Етап по маршрута
├── DailyEntry.kt     → Дневен запис
├── UserProgress.kt   → Напредък по маршрут
└── Achievement.kt    → Постижение
```

### 💾 Data Layer (Storage)
```
data/
├── local/
│   ├── VeloDatabase.kt      → Room Database
│   ├── DailyEntryDao.kt     → Операции с записи
│   ├── UserProgressDao.kt   → Операции с напредък
│   └── AchievementDao.kt    → Операции с постижения
│
├── repository/
│   └── VeloRepository.kt    → Единна точка за данни
│
└── Routes.kt                → Предефинирани маршрути
```

**Предимства на тази архитектура:**
- ✅ Лесна за тестване
- ✅ Ясно разделение на отговорностите
- ✅ Лесна за разширяване
- ✅ Независими компоненти

```kotlin
data class Milestone(

    val cityName: String,        // "Велико Търново"
    val description: String = "" // "Старата столица"
)
```

### DailyEntry (Дневен запис)

```kotlin
@Entity(tableName = "daily_entries")
data class DailyEntry(
    @PrimaryKey(autoGenerate = true)
    val id: Long = 0,
    val routeId: String,         // "sofia-varna"
    val date: Long,              // timestamp
    val kmRidden: Double,        // 15.5
    val notes: String = ""       // опционални бележки
)
```

### UserProgress (Напредък)

```kotlin
@Entity(tableName = "user_progress")
data class UserProgress(
    @PrimaryKey

    val totalKmCompleted: Double = 0.0,

    val lastUpdateDate: Long,
```

## 4. Примерен Compose UI

### Основен екран (опростен):

```kotlin
@Composable
fun HomeScreen(viewModel: HomeViewModel) {
    val currentRoute by viewModel.currentRoute.collectAsState()
    val progress by viewModel.progress.collectAsState()
    val kmInput by viewModel.kmInput.collectAsState()
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp)
    ) {
        // Карта с напредък
        Card(
            colors = CardDefaults.cardColors(
                containerColor = MaterialTheme.colorScheme.primaryContainer
            )
        ) {
            Column(modifier = Modifier.padding(20.dp)) {
                Text(
                    text = currentRoute?.name ?: "",
                    style = MaterialTheme.typography.headlineSmall
                )
                
                Spacer(modifier = Modifier.height(16.dp))
                
                // Прогрес бар
                LinearProgressIndicator(
                    progress = { 
                        (progress?.totalKmCompleted ?: 0.0) / 
                        (currentRoute?.totalKm ?: 1.0)
                    },
                    modifier = Modifier.fillMaxWidth()
                )
                
                Spacer(modifier = Modifier.height(12.dp))
                
                Row(
                    modifier = Modifier.fillMaxWidth(),
                    horizontalArrangement = Arrangement.SpaceBetween
                ) {
                    Text("${progress?.totalKmCompleted} км")
                    Text("${currentRoute?.totalKm} км")
                }
            }
        }
        
        Spacer(modifier = Modifier.height(24.dp))
        
        // Форма за въвеждане
        Card {
            Column(modifier = Modifier.padding(20.dp)) {
                OutlinedTextField(
                    value = kmInput,
                    onValueChange = { viewModel.onKmInputChange(it) },
                    label = { Text("Километри") },
                    modifier = Modifier.fillMaxWidth()
                )
                
                Spacer(modifier = Modifier.height(16.dp))
                
                Button(
                    onClick = { viewModel.addKilometers() },
                    modifier = Modifier.fillMaxWidth()
                ) {
                    Text("Добави")
                }
            }
        }
    }
}
```

### ViewModel пример:

```kotlin
class HomeViewModel(
    private val repository: VeloRepository
) : ViewModel() {
    
    private val _kmInput = MutableStateFlow("")
    val kmInput: StateFlow<String> = _kmInput
    
    val progress = repository.getCurrentActiveRoute()
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), null)
    
    fun onKmInputChange(value: String) {
        if (value.matches(Regex("^\\d*\\.?\\d*$"))) {
            _kmInput.value = value
        }
    }
    
    fun addKilometers() {
        val km = _kmInput.value.toDoubleOrNull() ?: return
        val routeId = progress.value?.routeId ?: return
        
        viewModelScope.launch {
            repository.addDailyEntry(routeId, km)
            _kmInput.value = ""
        }
    }
}
```

## 6. Компилиране без Android Studio

### Изисквания:

1. **JDK 17**
   - Изтеглете: https://adoptium.net/
   - Инсталирайте и добавете в PATH

2. **Android SDK Command Line Tools**
   - Изтеглете: https://developer.android.com/studio#command-tools
   - Инсталирайте SDK компоненти:
   ```cmd
   sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"
   ```

### Компилиране (Windows):

```cmd
# В папката на проекта
gradlew.bat assembleDebug
```

### Резултат:

APK файл: `app\build\outputs\apk\debug\app-debug.apk`

### Инсталиране на телефон:

```cmd
adb install app\build\outputs\apk\debug\app-debug.apk
```

### Алтернатива: GitHub Actions

1. Качете проекта в GitHub
2. GitHub Actions автоматично ще компилира
3. Изтеглете APK от раздел "Actions" → "Artifacts"
